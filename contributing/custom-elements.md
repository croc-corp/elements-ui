# Custom elements

Pixel Lab and Pixel HD are framework-free custom elements in strict TypeScript. They are canvas-heavy, run
in any page or framework, and reach React through a typed wrapper that `pnpm catalog` generates. Read
[Conventions](conventions.md) first; it applies here in full.

## Files

| File | Contents |
| --- | --- |
| `registry/components/lumesec/{tag}.element.ts` | The element. Importing it registers the tag. |
| `registry/components/lumesec/{tag}.tsx` | The React wrapper, generated by `pnpm catalog`. Never edit it by hand. |
| `content/meta/{tag}.json` | The notes the docs page and the wrapper are generated from |
| `content/catalog.json` | The catalog entry, including the demo markup (`stage`) |
| `src/components/preview/demo-setups.ts` | Optional wiring for the demo: buttons, timers, scripted sequences |
| `registry/lib/lumesec/pixel.ts` | The engine every element extends |

## The engine

`registry/lib/lumesec/pixel.ts` holds the shared runtime. The classes:

| Class | For | Gives you |
| --- | --- | --- |
| `Base` | Elements without a canvas loop | An open shadow root with the shared tokens CSS, your CSS and your template; `$()`, `$$()`, `emit()`, `num()` |
| `PxBase` | Pixel Lab | `Base` plus a canvas loop: finds `canvas.px` in the template, sizes it to the device pixel ratio, caches the theme palette, and runs `render()` on animation frames only while the element is on screen |
| `HF` | Pixel HD | `PxBase` plus a fine dot field (`this.F`, a `Field`) with bloom and ordered dither |
| `FormMixin(PxBase)`, `FormMixin(HF)` | Form controls | Form association through `ElementInternals`: `setFormValue()`, `setValidity()`, `form`, `name` |

The lifecycle hooks are optional methods you override:

| Hook | Called | Use it to |
| --- | --- | --- |
| `constructor()` | When the element is created | Call `super(css, html)` (for `HF`: `super(css, html, pitch, dot)`) and add listeners to your own template nodes. Attributes are not available yet. |
| `init()` | Once, on the first connect | Read the attributes and set the initial state. `this.initialized` is `true` afterwards. |
| `resized()` (`PxBase`) or `layout()` (`HF`) | On the frame after the canvas changed size | Recompute geometry. `this.w` and `this.h` hold the size in CSS pixels; for `HF` the field is already rebuilt. It runs outside the resize observer, so it may change the element's own size. |
| `render(t, dt)` | On an animation frame | Draw one frame. `t` is the time in seconds, `dt` the frame delta (at most 0.05 s). Return `true` to request another frame, `false` to stop until the next `kick()`. |

Inside an element:

- `this.$<T>(selector)` and `this.$$<T>(selector)` query the shadow root, typed (`this.$("canvas")` is an
  `HTMLCanvasElement`).
- `this.emit<Detail>(type, detail, options?)` dispatches a `CustomEvent` that bubbles and crosses the shadow
  boundary. Pass `options` only to change that, such as `{ bubbles: false, composed: false }`.
- `this.num(name, fallback)` reads a numeric attribute.
- `this.kick()` schedules a frame. Call it whenever the state that the drawing depends on changes.
- `this.P` is the palette (`accent`, `shine`, `fg`, `muted`, `track`, `danger`, `ok`, `warn`, `surface`,
  `raised`, `border`), resolved from the theme and cached until the theme changes.
- `this.clear()` and `this.dot(x, y, color, alpha, size)` draw on the canvas; `HF` adds `this.F.put()`,
  `this.F.plot()`, `this.F.base()`, `this.F.clear()` and `this.flush()` for the dot field.
- `this.monoFont` is the resolved monospace font stack for text drawn in a canvas.
- `this.onScreen` tells whether the element is in the viewport; frames are only drawn while it is.

Module helpers include `define`, `reduced`, `rollText`, `pixelBurst`, `Sparks`, `shake`, `escapeHtml`, `clamp`,
`lerp`, `mix`, `css`, `hash`, `strHash`, `ease3`, `bayer`, `fbm`, `isDark`, `pad2` and `fmtInt`. For pointer
input and layout inside CSS-zoomed or scaled containers, use `localPoint(el, event)` (a pointer in `el`'s own
CSS pixels), `boxMapper(origin)` (rects of other nodes relative to `origin`) and `clientScale(el)`. Radio groups
use `radioKeys()` and `checkRadio()` for the arrow keys and the roving tab index. Read the module before you add
a helper of your own.

The shared CSS that every shadow root receives defines the private tokens and a few classes:

| Token | Reads | Token | Reads |
| --- | --- | --- | --- |
| `--_surface` | `--ui-surface`, `--card` | `--_accent` | `--ui-accent`, `--lumesec` |
| `--_raised` | `--ui-raised`, `--muted` | `--_on-accent` | `--ui-on-accent`, `--lumesec-foreground` |
| `--_track` | `--ui-track`, `--muted` | `--_shine` | `--ui-shine`, `--lumesec-shine` |
| `--_border` | `--ui-border`, `--border` | `--_ok` | `--ui-ok`, `--lumesec-success` |
| `--_fg` | `--ui-fg`, `--foreground` | `--_warn` | `--ui-warn`, `--lumesec-warning` |
| `--_muted` | `--ui-muted`, `--muted-foreground` | `--_danger` | `--ui-danger`, `--destructive` |
| `--_font` | `--ui-font`, `--font-sans` | `--_mono` | `--ui-mono`, `--font-mono` |

Each token falls back to a built-in light or dark value, so an element also works on a page without a theme.
Use only these tokens in your CSS. The classes are `canvas.px` (the canvas `PxBase` drives), `.mono`, `.pbtn`
(a small button), `.rollslot` (a slot for `rollText()`), `.sr` (visually hidden text for screen readers) and
`.fxl` (the overflow layer `pixelBurst()` draws into, 40px past every edge).

## A minimal element

```ts
/**
 * <hf-example> · Example
 * LumeSec Elements · Pixel HD · https://elements.lumesec.ai/components/pixel-hd/example
 *
 * A framework-free custom element. Importing this module registers the tag.
 * The React wrapper is ./hf-example.tsx.
 */
import { HF, clamp, define, rollText } from "@/lib/lumesec/pixel";

/** Events fired by `<hf-example>`. */
export interface HExampleEventMap {
  /** Fires when the user steps the value. */
  change: CustomEvent<{ value: number }>;
}

/** A level from 0 to 100 on a dot field, with the number as text. */
class HExample extends HF {
  static readonly observedAttributes = ["value"] as const;

  private current = 0;

  constructor() {
    super(
      `
      :host { display: block; }
      canvas.px { height: 48px; }
      .v { font-family: var(--_mono); font-variant-numeric: tabular-nums; }
      `,
      `<canvas class="px" role="slider" tabindex="0" aria-label="Level" aria-valuemin="0" aria-valuemax="100"></canvas>
      <span class="rollslot v" aria-hidden="true"></span>`,
    );
    this.$("canvas").addEventListener("keydown", (event) => {
      const step = event.key === "ArrowRight" ? 1 : event.key === "ArrowLeft" ? -1 : 0;
      if (!step) return;
      event.preventDefault();
      this.apply(this.current + step, true);
    });
  }

  /** Current value, 0 to 100. Setting it does not fire `change`. */
  get value(): number {
    return this.current;
  }

  set value(value: number) {
    this.apply(value, false);
  }

  protected override init(): void {
    this.apply(this.num("value", 40), false, true);
  }

  attributeChangedCallback(): void {
    // before the first connect, init() reads the attribute
    if (this.initialized) this.apply(this.num("value", 40), false);
  }

  private apply(raw: number, emit: boolean, first = false): void {
    const value = Math.round(clamp(raw, 0, 100));
    if (value === this.current && !first) return;
    const direction = value >= this.current ? 1 : -1;
    this.current = value;
    rollText(this.$(".v"), String(value), direction, !first);
    this.$("canvas").setAttribute("aria-valuenow", String(value));
    if (emit) this.emit<{ value: number }>("change", { value });
    this.kick();
  }

  protected override render(): boolean {
    const P = this.P;
    const F = this.F;
    F.base(P.fg, 0.06);
    const lit = Math.round((F.cols * this.current) / 100);
    for (let i = 0; i < lit; i++) {
      for (let j = 0; j < F.rows; j++) F.put(i, j, P.accent, 0.9, 0.4);
    }
    this.flush();
    return false;
  }
}

define("hf-example", HExample);

export { HExample };

declare global {
  interface HTMLElementTagNameMap {
    "hf-example": HExample;
  }
}
```

## Attributes and properties

- Read attributes where they are used: `this.num("value", 42)` for numbers,
  `this.getAttribute("label") || "Rate limit"` for strings, `this.hasAttribute("disabled")` for presence
  attributes. The fallback in code is the documented default.
- List the attributes that should update a connected element in
  `static readonly observedAttributes = [...] as const`, and guard `attributeChangedCallback` with
  `this.initialized`, because it also runs before the first connect.
- Attributes with a closed set of values get an exported string-literal union
  (`export type OrbState = "idle" | "listening" | ...`).
- Attribute-backed properties are typed getters and setters. A read-only property has a getter only; say so
  in the notes.
- A property assigned before the tag was defined sits on the instance and hides the accessor. The engine
  removes it and assigns it again through your setter after `init()`, on the first connect. Elements whose
  first frame must already use the data (`hf-area`, `hf-candles`) recover it in the constructor instead.
- Records go in `data`, as a property and as JSON in the attribute. Parse them with `readJson`, `rows`,
  `isRecord`, `finite`, `text` and `toDate` from `@/lib/lumesec/data`: invalid entries are dropped, invalid
  JSON logs one warning and falls back to the demo data, and an empty array shows an empty state.
- Every field is declared with its type and a `private`, `protected` or `readonly` modifier where it applies.

## Events

- Fire events with `this.emit<Detail>(name, detail)`. Use plain names (`change`, `input`, `select`) and a
  detail object, even for a single value.
- Export an event map named after the exported class, `{Class}EventMap`, with one `CustomEvent<Detail>` per
  event and a JSDoc on each. `pnpm catalog` finds it by that name and types the wrapper's `on{Event}` props
  from it. Without it the wrapper falls back to the `detail` written in the notes.

## Registration and types

- The module ends with `define("{tag}", Class)`, `export { Class };` and the `HTMLElementTagNameMap`
  declaration, so `document.querySelector("{tag}")` and React refs are typed with the class.
- `define()` registers a tag once and does nothing on the server, so two bundles that both contain an
  element can share a page.
- The file starts with the header comment shown above: tag, title, collection and docs URL. Elements that show
  data add a line on what they take (`Data: set data ...`) or that they only show demo data.

## Markup and escaping

- Build the template once, in the constructor. Update text with `textContent`.
- When you build markup from values, pass every value through `escapeHtml()`:
  `` row.innerHTML = `<span class="n">${escapeHtml(item.label)}</span>` ``.
- Never put user input into attributes without `escapeHtml()`, and never into `on*` attributes or `<style>`.

## Lifecycle and cleanup

`PxBase` already handles the animation frame, the resize and intersection observers, the theme watcher and
resuming after a hidden tab. If the element starts its own timers or observers, override the callbacks, call
`super`, and clean up:

```ts
override connectedCallback(): void {
  super.connectedCallback();
  this.timer = window.setInterval(() => this.tick(), 1000);
}

override disconnectedCallback(): void {
  super.disconnectedCallback();
  window.clearInterval(this.timer);
}
```

An element can be removed and inserted again, so restart in `connectedCallback` what `disconnectedCallback`
stopped. `init()` runs only once.

## Reduced motion

`reduced()` reports `prefers-reduced-motion: reduce` on every call. `rollText()`, `pixelBurst()`, `Sparks` and
`shake()` already respect it. In `render()`, skip loops, shimmer and traffic and jump to the target state, and
return `false` once nothing changes.

## Forms

```ts
class HToggle extends FormMixin(HF) {
  private on = false;

  /** Whether the toggle is on. */
  get checked(): boolean {
    return this.on;
  }

  private setOn(on: boolean): void {
    this.on = on;
    this.setFormValue(on ? "on" : null);
    this.kick();
  }

  formResetCallback(): void {
    this.setOn(this.hasAttribute("checked"));
  }

  override formDisabledCallback(disabled: boolean): void {
    super.formDisabledCallback(disabled);
    this.$("button").disabled = this.formDisabled;
  }
}
```

- `setFormValue()` sets the submitted value; the field name is the `name` attribute.
- `setValidity(flags, message, anchor)` reports validation state; `{}` marks the element valid.
- Implement `formResetCallback()` when the element should return to its attribute value on form reset.
- `FormMixin` records a disabled fieldset; `this.formDisabled` covers it and the `disabled` attribute. Override
  `formDisabledCallback()` to disable inner controls, and call `super`. Add `DISABLED_CSS` to the element's
  styles for the shared `:host(:disabled)` look.
- Describe the result in the notes (`form`): what is submitted under `name`, whether there is validation,
  what reset does.

## The React wrapper

`pnpm catalog` writes `{tag}.tsx` from the class and the notes:

- each attribute in the notes becomes a camelCase prop. Its type comes from the notes: `number`, `boolean`,
  a union of words (`"low" | "medium" | "high"`), `json` with a `tsType`, or `string` otherwise;
- each event becomes an `on{Event}` prop typed from the event map;
- `ref` is typed as the element class, and the `{Name}Element` type is exported;
- `className`, `style`, `id`, `slot`, `aria-*` and `data-*` pass through, and children render into the slots.

The wrapper passes attribute names upper-cased, because React 19 assigns a prop to a same-named element
property when one exists, which throws on getter-only properties such as `name`. The browser lower-cases
the names again. If the wrapper is wrong, fix the notes or the element and run `pnpm catalog` again.

## The demo

The preview renders the `stage` markup of the catalog entry. Lay it out with the `.stage` helper classes in
`src/app/globals.css` (`panel`, `col`, `row`, `ctl` for a row of demo buttons), and set `layout` to `center`,
`fill` or `wide`. When the demo needs behaviour, such as buttons that change a value or a timed sequence, add
a setup for the tag in `src/components/preview/demo-setups.ts`: it receives the preview root, only touches the
demo markup, and returns a cleanup. `markup`, when set, is the snippet the usage section starts from; without
it the snippet is derived from `stage`. `tryText` tells the reader what to try.

## The notes

```json
{
  "summary": "Pixel disc showing an agent's state (idle, listening, thinking, working, error, done), dissolving cell by cell between states.",
  "attributes": [
    { "name": "state", "type": "\"idle\" | \"listening\" | \"thinking\" | \"working\" | \"error\" | \"done\"", "default": "thinking", "description": "Initial state. Read once when the element first connects; use `set()` to change it afterwards." }
  ],
  "events": [
    { "name": "change", "detail": "{ state: OrbState }", "description": "Fires when the state changes after the initial render." }
  ],
  "methods": [
    { "signature": "set(state: OrbState)", "description": "Switches to one of the six states and fires `change`." }
  ],
  "properties": [
    { "name": "state", "type": "OrbState", "readonly": true, "description": "The current state. Use `set()` to change it." }
  ],
  "keyboard": [{ "keys": "Enter / Space (on the orb)", "action": "Cycle to the next state." }],
  "accessibility": ["The state name under the orb is an `aria-live=\"polite\"` region."],
  "motion": "With reduced motion, a new state replaces the old one at once instead of dissolving pixel by pixel.",
  "slots": [],
  "notes": ["The orb canvas is a fixed 164 by 164px and is followed by one button per state."],
  "data": { "kind": "input", "note": "Set the agent's state with `state`. Without it the orb starts at `thinking`." }
}
```

| Field | Contents |
| --- | --- |
| `summary` | One sentence of at most about 150 characters: what the element is and its one notable behaviour. It becomes the page's meta description, the registry description and the wrapper's JSDoc. |
| `attributes` | Every real input. `type` is `number`, `boolean` (a presence attribute), `string`, a union of quoted words, or `json` with a `tsType` that names a type exported from the element module (`"readonly ElementModule.HfAreaDatum[]"`). `default` is the fallback in code as a string; omit it when there is none. Say in the description whether the attribute is observed. Leave out attributes the element reflects for itself and `data-*`. |
| `events` | `detail` is the shape passed to `emit()`. Say when an event does not bubble. |
| `methods` | The public API a developer calls (`run`, `set`, `push`, `restart`), with the signature. Not the lifecycle hooks, `render`, `layout` or private helpers. |
| `properties` | Public getters and setters, with `readonly` for getters without a setter. |
| `keyboard` | Exactly what the `keydown` handlers do. Empty when there are none. |
| `accessibility`, `motion`, `form`, `notes` | As for React components: factual statements; `motion` is what reduced motion changes; `form` only for form-associated elements. |
| `slots` | Named slots and the default slot (`""`), with what they hold. |
| `data` | Only for elements that display records: `{ "kind": "input", "note": "..." }` when it takes your data, naming the attribute; `{ "kind": "demo", "note": "..." }` when it can only show invented data. |

The playground on the docs page offers a control for each attribute in the notes, except `json` ones.
Observed attributes update live; the others rebuild the element.
